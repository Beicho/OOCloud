# OOCloud

OOCloud 是一个基于 PHP 的轻量网盘 / 外链分享服务，支持所有常见文件格式上传，自动生成直链、图片/音视频外链与对应的 UBB/HTML 代码，并内置文本、图片、音频、视频的在线预览。支持多种对象存储（阿里云 OSS、腾讯云 COS、华为云 OBS、又拍云、七牛云等），并可选开启图片违规检测。

本项目为“彩虹外链网盘”的二次开发与重命名版本，项目名统一更改为 OOCloud。感谢原项目及其社区的出色工作与启发。

### 部署方法

- 环境要求 `PHP >= 7.1`、`MySQL >= 5.5`
- 将项目上传到站点根目录，直接访问，按引导完成安装
- 初始后台账号密码：`admin / 123456`
